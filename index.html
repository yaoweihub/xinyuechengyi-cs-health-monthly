执行摘要

本页对比客户鑫悦诚毅（org 10535）在 2026.09 全月（上期）与 2026.10 全月（本期）的客服健康指标（全平台汇总，共 47 项），并以 2026.08 全月作参考基线。三个月均为完整月（已逐日探针确认 10-31 有数据，9 月 30 天、10 月 31 天），计数 / 金额类按日均折算后再比，比率与时长直接比较。总体呈「单量回正、客单价两月连降；人工接待腰斩退场、机器人独撑；弃单率再创新低，但沟通挽回率已跌破「不沟通」——服务正在从加分项变成无效功」的格局。 量回来了，钱没回来：订单数 69,046 → 74,006（+3.7%，日均），日均 2,302 → 2,387 单（8 月日均 2,350 单，本期较之 +1.6%）；但订单金额 ¥250.0万 → ¥247.8万，日均 -4.1%；单均 ¥36.2 → ¥33.5（-7.5%），而 8 月还是 ¥38.3——两个月累计 -12.5%，单量涨的都被单价吃掉了。支付端没有拖后腿：非 COD 订单占比 25.49% → 22.78%，付款率 91.01% → 90.94%（-0.07pp），稳定在九成以上——问题不在付款能力，在成交价本身在下移。 人工几乎退场，机器人独撑门面：接待买家 1,745 → 1,536（-14.8%，日均），接待覆盖率 2.53% → 2.08%（8 月 2.43%）；结构上人工 953 → 550（日均 -44.1%，较 8 月 836 已收缩 34.2%）、机器人 985 → 1,159（日均 +13.9%），机器人占比 56.45% → 75.46%（+19.01pp；8 月 61.16%）——每 4 个被接待的买家有 3 个只见到了机器人。接待转化率 12.89% → 16.93%（+4.04pp），是三个月最高，但拆开看：机器人 20.41% → 19.93%（-0.48pp；8 月 20.52%，三月连降），人工 4.09% → 7.45%（+3.36pp）——整体转化率的好看，来自「接入的人更少、筛得更准」，不是两端各自变强。更要紧的是钱：接待后下单买家 225 → 260（日均 +11.8%），但接待后下单金额 ¥12,417 → ¥10,683（日均 -16.7%），人均接待产出从 ¥55 掉到 ¥41（-26%）——成单更多、单子更小，服务在「促成交」上有效，在「促客单」上无效。 响应是一条「均值更差、中段略好」的分裂曲线：人工平均响应 15h32m → 22h51m（+439min / +47.1%），买家咨询平均等待 15h33m → 22h52m；但 60 分钟内响应率反而 15.75% → 20.58%（+4.83pp）、1 分钟内 2.98% → 3.60%（+0.62pp）、5 分钟内 4.91% → 5.92%（+1.01pp）。响应问题数同期 3,829 → 2,668（日均 -32.6%）——问题量少了三成，中段提速其实是「分母变小」；而均值被更极端的长尾拉高：60 分钟内只有 20.58% 的会话被人工响应，平均等待却接近一整天，说明少数会话挂了好几天没人接。这是本期最需要正视的结构问题：5 分钟内响应率只有 5.92%。 弃单率再创新低，但改善全部来自「想弃的人变少」，不来自「接住的人变多」：最终弃单率 8 月 14.22% → 13.17% → 12.83%（-0.34pp），最终弃单 9,092 → 9,497 单（日均 +1.1%）、金额 ¥33.0万 → ¥30.8万（日均 -9.6%）。发起端：可挽回弃单 10,445 → 10,742（日均 -0.5%，基本走平），发起弃单率 15.13% → 14.52%（-0.61pp）——分子在缩小，这是好消息。服务端却在退：弃单沟通率 55.13% → 62.60%（+7.47pp；沟通 5,758 → 6,724 单，日均 +13.0%），沟通后挽回率 18.63% → 15.88%（-2.75pp，8 月 22.28%，三月连降），而未沟通的单自然挽回率却一路走高 15.90% → 17.52% → 18.34%（+0.83pp）——本期两条线首次交叉：沟通的 15.88% 已经低于没沟通的 18.34%。挽回数 1,894 → 1,805（日均 -7.8%），单位沟通产出 0.33 → 0.27 单——沟通量涨了 13%，挽回数反而少了 8%。分链路：机器人沟通 5,373 → 6,451 单、挽回率 18.20% → 15.75%（-2.45pp）；人工 692 → 584 单、挽回率 24.42% → 20.38%（-4.05pp）——两条链路同时在退，跟单助手的边际效益已经明显递减。跟单助手的能力面倒是齐的：物流呵护 40,962 → 43,334 张、覆盖率 96.46% → 96.23%（未呵护仅 1,696 张），催付覆盖 85.84%、催付后付款率 23.64%；「已支持」却零触达的原因只剩 1,278 单（占发起可挽回 11.9%）。能力不缺，缺的是「该跟谁」的判断。

结论与建议

主线是「率在变好，能力在变弱」。10 月订单日均 2,387 单、较 9 月 +3.7%，但金额日均 -4.1%、单均 ¥36.2 → ¥33.5（-7.5%，相对 8 月累计 -12.5%）。最终弃单率三连降（14.22% → 13.17% → 12.83%）、最终弃单金额日均 -9.6%，账面确实越来越好看；但支撑它的两件事都不是服务赚来的：一是发起弃单率从 16.65% 降到 14.52%（-2.13pp），想弃的人本来就少了；二是沟通后挽回率从 22.28% 一路掉到 15.88%（-6.39pp），而没沟通的单自然挽回率同期从 15.90% 升到 18.34%。一条向下、一条向上，10 月正式交叉——此刻的「跟单沟通」整体上是在拉低而不是拉高挽回概率。 三个必须盯的口子。一是人工接待已经接近停摆：人工接待买家 836 → 953 → 550，平均响应 22h51m，5 分钟内响应率仅 5.92%、60 分钟内 20.58%——近八成买家一小时内等不到人工回复；机器人占比 75.46%、机器人转化率却三连降至 19.93%，这个组合撑不住客单价。二是沟通预算错配在最不可能挽回的原因上：Package delivery failed 本期 1,739 单（较上期 1,535 单，+13.3%），机器人沟通率 49.74%，但挽回率只有 1.04%（沟通 865 单、挽回约 9 单）；加上不在支持清单的 Failed Delivery 955 单（挽回率 4.94%），这两类「物流已失败」的单合计占发起可挽回 25.1%，却在吃掉大量沟通产能。对照之下，Need to change delivery address 的挽回率是 31.52%、Need to change payment method 是 22.97%——真正值得跟的单，恰恰不是现在被重点跟的那批。三是客单价两月连降：¥38.3 → ¥36.2 → ¥33.5，而接待后人均产出从 ¥55 掉到 ¥41——服务能促成下单，却促不动加购与连带。 建议下一周期：① 先给人工接待止血——当前 60 分钟内被接待率只有 20.58%、平均响应 22h51m，已经不是「慢」，是「缺岗」；按客服维度看本期只有 lin008（526 人 / 响应 25h59m）与「非乐聊帐号」（27 人 / 响应 5h52m）在接，机器人账号 +8615353756279（1,159 人）独自承担了 75.46% 的接待——建议把「5 分钟内响应率」「60 分钟内被接待率」设为日报阈值，并按高客单 / 复购会话做优先派单，先接住那 79% 一小时内等不到人工的买家；② 按原因重建沟通策略，把产能从「物流已失败」挪到「还来得及」——Package delivery failed 这类单沟通产能在打水漂（挽回率 1.04%，865 单只换回约 9 单），建议直接降级为「通知 + 转人工兜底」，把释放出的沟通量投到 Need to change delivery address（挽回率 31.52%）、Need to change payment method（22.97%）、Product is defective（28.57%）这类「改一下就成」的原因上；同时把 1,278 单零触达的已支持原因（11 类，含 Others 653 单、沟通率 0%）全部接进机器人，按现行 15.75% 测算理论上限约 201 单 / 月；③ 给「沟通后挽回率」设熔断线——它已连续三个月下滑并跌破未沟通组（15.88% vs 18.34%），建议按原因分组做 A/B：同原因随机一半不沟通，两周后比较两组挽回率，把「沟通无效」的原因从流程里摘掉。只调话术解决不了配置错配，必须让「不沟通」也成为一种可被选择的策略。
